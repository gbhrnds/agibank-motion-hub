# agibank-motion-hub

Hub de motion do Agibank: fontes, logos, ícones, formas e regras de marca (`docs/`, `assets-map.md`).

- Para criar **letterings/GC/cards animados em vídeo**, use a skill `skill-motion`
  (`.claude/skills/skill-motion/SKILL.md`). Implementação de referência: `projetos/estagio-matheus-vs01/`.
- Entrega de letterings com transparência: **.mov QuickTime Animation (RGB+alpha)** — é o formato que
  funciona no Premiere Pro do time; o ProRes 4444 do ffmpeg apareceu preto.
- Nunca versionar vídeos (`*.mp4`, `*.mov`); mostrar prévias para aprovação antes do render final.
- Comunicação com o time em português.
